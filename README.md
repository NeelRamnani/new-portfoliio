# Neel Ramnani — Portfolio

Static HTML, CSS and JavaScript portfolio with light/dark themes, animated hero videos, glowing navigation and project galleries.

## Deploy on Vercel

Import this repository in Vercel. Use the Other framework preset, an empty build command, and dist as the output directory.

## Local preview

Run `python3 -m http.server 8000 --directory dist` and open http://localhost:8000.

Email gallery entries marked Concept are illustrative designs, not client campaigns.
